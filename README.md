# Study Material Website

A colorful and modern personal website for uploading and downloading study materials.

## Features
- Admin login to upload/delete files (password: `2KD22AD036`)
- Users can enter their name and download materials
- Simple and responsive interface using Tailwind CSS

## Setup Instructions
1. Clone this repo
2. Use with any static server or add backend (Flask/Node.js) for file handling
3. Files are stored in `uploads/` directory
